Cómo «ve» la red un dígito

Para la red, una imagen es una tabla de números. En MNIST cada píxel vale entre 0 y 1:

  • 0 = negro = fondo (no hay tinta).
  • 1 = blanco = trazo (tinta máxima).
  • Valores intermedios = bordes grises del trazo.

Blanco y negro no significan «reconocido» o «no reconocido»: solo indican dónde hay tinta. Las redes aprendieron con esta convención, así que toda entrada se convierte a ella antes de predecir. Un número negro sobre papel blanco tiene los valores al revés (fondo = 1) y la red vería algo que nunca vio al entrenar.

Fórmulas

Normalización (una sola vez): x = p / 255,  p ∈ {0, …, 255}

Inversión de polaridad: p′ = 255 − p

Centro de masa: r̄ = Σ r·xr,c / Σ xr,c,  c̄ = Σ c·xr,c / Σ xr,c — la imagen se desplaza para que (r̄, c̄) = (14, 14), igual que en MNIST.

Con cámara se agrega una limpieza: el umbral de Otsu separa automáticamente papel y tinta, y los grises del papel o de las sombras pasan a 0.

Red densa (perceptrón multicapa)

La imagen de 28×28 se aplana: las 28 filas se colocan una detrás de otra y queda un vector de 784 números. Cada neurona de una capa densa mira todos esos números a la vez, los multiplica por pesos, suma un sesgo y aplica ReLU. La última capa usa softmax para producir 10 probabilidades que suman 1.

h = max(0, W·x + b)   pk = ezk / Σj ezj

Input(784) → Dense(64, relu) → Dense(64, relu) → Dense(10, softmax)

Red convolucional

En lugar de aplanar desde el principio, la CNN conserva la forma 28×28. Cada filtro es una ventana de 3×3 pesos que se desliza por la imagen y responde fuerte donde encuentra su patrón (un borde, una curva). El resultado es un mapa de características. Sin padding, cada convolución 3×3 reduce el tamaño en 2: 28 → 26 → 24. Después Flatten convierte los 24×24×64 valores en un vector y la capa softmax decide la clase.

yi,j = ReLU( Σu,v wu,v · xi+u, j+v + b )

Input(28×28×1) → Conv2D(32, 3×3, relu) → Conv2D(64, 3×3, relu) → Flatten → Dense(10, softmax)

Sin pooling ni dropout: arquitectura fiel a scratchpad.py. Por eso casi todos los parámetros están en la capa final (36 864 × 10 + 10).

Qué aprendió la primera capa

16 de los 32 filtros 3×3 (claro = peso positivo, oscuro = negativo). Son pesos aprendidos, no etiquetas con significado humano.
